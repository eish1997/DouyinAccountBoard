# 抖音账号工作台

双击桌面“抖音账号工作台”快捷方式，或 `desktop/抖音账号工作台.exe`、`启动看板.bat` 即可打开独立桌面窗口，无需额外安装 Python 或打开浏览器。

桌面版内部服务使用随机本机端口，关闭窗口时自动停止；重复启动只会唤回已有窗口。
数据仍存储在项目原有 `data/board.db`，界面缓存位于 `desktop-profile`，日志位于 `logs/desktop.log`。
“工作台 → 备份账号数据”可在软件运行时安全备份 SQLite；“帮助 → 打开数据文件夹”可定位数据。

这是本机免安装桌面版。请保留整个项目目录，不要只移动 exe；若换电脑，需要一起复制项目并重新创建快捷方式。
桌面运行环境复用本机已有 Electron / Python，保留运行环境许可证。

源码网页入口仍可通过 `python app.py` 启动到 http://127.0.0.1:8776 ，不属于桌面版的日常操作步骤。

## 导入口径

图片前缀数字仅为内部账号编号，不是抖音号。括号数字含义未确认，只保存在备注。
图片中的远程密码和远程连接代码未保存。只有48号账号的文字明确标注短期封禁；其他账号设为待确认，颜色不用于推断状态。可在账号管理中批量改成正常。
导入一次后，修改不会被再次启动覆盖。每日默认未发；这不代表影刀实际未执行，仅表示尚未登记。

## 公开作品数量采集

在“账号管理 → 编辑”填写真实抖音号即可；公开主页链接选填。
软件优先读取已绑定的主页。未绑定时，通过抖音用户搜索查找，只有结果抖音号完全一致且唯一，才自动绑定主页。
仅解析公开主页“作品”标签旁的明确整数，不累计已加载的视频卡片，不采用搜索条数，不把万/亿的近似显示换算成精确数量。

- 软件打开时，“每日自动采集”默认开启，每个已配置账号每天尝试一次，顺序执行。
- 可对筛选账号、勾选账号或单个账号手动重新采集。
- 成功更新作品数和最后成功时间。失败保留旧值，单独显示采集状态与错误原因，不改变人工账号状态或每日发布标记。
- 验证码、登录要求或空白页面会暂停队列并显示采集浏览器；请用户手动处理，再点击“继续采集”。不会自动处理验证码。
- 修改真实抖音号或主页后清空旧数量，避免跨账号沿用数据。
- 软件关闭后不执行采集。网络、登录状态和平台页面变化可能导致采集失败。

## 手机卡管理

左侧“手机卡管理”为独立工作空间，支持新增、编辑手机号、卡编号、运营商、卡状态、负责人、存放位置、到期日期和备注。可搜索、按运营商/卡状态/账号关联/到期情况筛选，每页50条。到期提示包含已到期和未来7天内，不自动改变卡状态。

账号按注册手机号精确匹配展示关联，点击可跳转账号管理查看对应大小号及电脑。手机卡资料独立保存，修改卡状态或号码不会修改账号资料。“从账号手机号补录”仅新增尚未登记的有效号码，状态默认为待确认，不覆盖已有卡资料；用户点击后执行，升级时不自动补录。手机卡与账号同库，纳入现有自动备份。当前为本地单用户版，管理员/员工权限尚未实现。

手机卡资料可从腾讯文档快照按注册手机号去重导入，保留原卡主/位置/小号说明供核对，卡主多条不一致不猜归属，原表颜色不用于判断卡是否已注销。重复导入只补缺失字段，不覆盖人工维护；账号原有状态和发布记录不随卡导入改变。

手机卡状态增加“待注销”，指运营商手机卡处理，不是抖音账号注销。关联账号分别记录“待确认/未稳定/已稳定”和“待确认/未修改/已修改密码”，只保存状态，不保存密码。手机卡页“编辑/处理”可即时维护账号的这两项，账号详情也可编辑。永久封禁账号单独提示；已记录小号且未封禁的相关账号都标稳定、已改密时，可筛出供人工核对，软件不执行注销、不保证平台后续不需验证。

卡归属支持待确认/自有/借用/代管；另外记录卡主、负责人、接码联系人、接码状态和事项、归还状态及预计/实际日期。标记已归还需实际日期。可筛选待注销/待接码/待归还/关联封禁/稳定改密已记录/源资料待核对；接码和归还独立，不因账号封禁自动注销卡、销号或通知他人。

## 手机设备管理

左侧“手机设备管理”与手机卡、发布电脑分别维护。账号当前登录手机从腾讯文档“抖音在哪个手机上”导入，以唯一抖音号优先匹配；无有效抖音号时，只使用唯一昵称或唯一昵称加注册手机号，不仅按原行号猜账号。数字与明确的“多开”后缀归到同一编号；“圆”“方1”“苹果13”等原文留账号详情待核对。已有人工登录位置不被重复导入覆盖。

自动判断下，有非封禁/停用的关联账号显示在用；仅封禁或停用显示待清理；无当前账号显示待确认。闲置必须移出当前账号、人工确认清理后标记“可用闲置”。设备状态支持人工覆盖与按账号自动判断，原有卡的位置不能决定当前登录账号。设备编号来源包括登录手机列与卡位置中的明确数字，未自行补全编号间的缺号。

可按设备状态或占用情况筛选，顶部待清理/可用闲置卡片可点击。1至6位数字搜索精确匹配手机编号，账号内部编号可输入“#编号”；可按账号昵称或真实抖音号搜索。设备编辑中可新增关联或移出已有账号，账号详情也可选择当前登录手机；换手机不改变注册卡、账号状态或发布电脑。仍有关联账号的手机不能标记可用闲置；已标故障的手机不接受新账号关联。手机账号是当前关系，不代表旧封禁账号被删除。

## 备份与恢复方式

软件运行时每4小时自动备份一次；启动时检查，距离上次备份不足4小时会复用已有备份。自动备份保存在 backups/automatic，保留最近30天，只有新备份通过完整性检查后才清理过期自动文件，手动备份不受影响。软件关闭时不备份，重新打开会补上到期备份。

页面底部显示最近自动备份时间，失败会在页面提示并每分钟重试；“帮助 → 打开自动备份文件夹”可查看文件。“工作台 → 备份账号数据”仍可手动备份。备份和数据都在本机E盘，不能防止同一硬盘损坏；重要备份可另存其他设备。恢复时先关闭软件，将选定备份复制为 data/board.db（先保留原文件）。请勿删除 board.db，否则会恢复初始导入状态。

新增、修改真实抖音号均校验重复；历史已有重复不自动合并，保留原抖音号时允许修改状态和备注。修改大号注册手机号若与已关联小号冲突（包括清空），会拒绝保存，需先核对或解除配对关系。
## 登录与人员权限（2026-10-17）

首次更新后，在服务器本机桌面软件创建总管理员，亲自输入姓名、登录名、至少10位密码及确认密码。没有默认账号或通用密码。初始化授权仅由本机桌面程序生成，30分钟有效；过期可正常关闭并重开软件。普通浏览器不能抢先注册总管理员，全库只能有一个总管理员。

登录后，右上角“人员与权限”仅总管理员可见，可以新增人员、逐项授权、停用人员或重设员工密码。普通管理员不能授权。管理员、员工、只读人员是默认勾选模板，以实际勾选为准；所有已登录人员默认查看三个办公室。

八类权限为：当天发布、账号状态、注册进度与稳定/改密记录、账号新增与基础资料、手机卡状态/接码/归还、手机卡新增与基础资料及补录、手机设备与账号关联、作品采集。基础资料授权不隐含其他字段的操作权限，后台强制校验。

总管理员可查看最近200条操作记录。调整权限、停用或重设密码后，对方原登录立即失效；本人改密码需要原密码，其他设备的旧登录失效。会话12小时，密码独立盐PBKDF2哈希保存，写请求校验CSRF，登录失败有限次等待。未提供远程总管理员恢复或转让入口，请保管登录信息。

本次只增加本地权限，服务仍绑定127.0.0.1，三个办公室尚未联网。后续HTTPS代理需要显式设置DOUYIN_BOARD_PUBLIC_ORIGIN为完整外部来源，用于Origin校验与Secure Cookie；不信任客户端转发头。

backups/auth-validation.db是本次验证副本，含虚拟测试登录人员，不得用于恢复正式数据。其临时服务51550已停止。自动审批拦截了最后的组合清理命令，故该副本保留；正式数据没有测试登录人员。
