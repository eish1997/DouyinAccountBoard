仅允许新建 `.synthetic-tests` 子目录，目录标识 synthetic-only/version=1。
测试启动器先安装 Python 审计钩子，再导入显式审查通过的测试模块。
拒绝正式目录读写、测试根外 SQLite 连接、非本机网络和未单独审查的子进程。
应用测试模式初始化使用代码生成的一台电脑、一个账号，不读取客户种子。
保护是经审查测试的纵深防御，不宣称代替操作系统沙箱；原有运行入口暂禁止直接执行。

Windows Python 3.14 TemporaryDirectory 的 ACL 在当前沙箱不可用，改用普通 mkdir 的唯一测试子目录并保留证据。

## D002 / 2026-10-21 / 运行入口不得隐式选择数据

app.py 的数据目录必须显式指定；非测试连接使用 SQLite mode=rw，不创建不存在的库。
非测试初始化在任何结构写入前确认已有初始化标识，不再读取 data/seed.json。
web_server.py 的 --config 必填；desktop_server.py 导入不启动服务，调用 main 时遵循相同数据目录规则。
兼容影响：历史 `python app.py` 无配置用法现在明确失败；桌面启动器必须显式提供数据目录。
不运行旧 import/reset 脚本，这些离线维护工具仍有硬编码正式路径，不进入发布白名单。
T05 将增加受控无图形初始化；本轮不伪造可部署状态或修改已有正式库。

## D005 / 2026-10-21 / 新账号内部标识

新建账号内部id改为account-加UUID4，SQLite与PG一致；已有id原样保留。内部标识不作为位置排序依据，位置仍取电脑及slot。取消MAX(CAST(id))+1，避免依赖SQLite宽松数字转换及并发计算最大值；不改变真实抖音号字段。回归覆盖新增、设备关联、养号和历史；未执行真实数据迁移。手机卡/人员/审计仍用数据库identity数值主键。
