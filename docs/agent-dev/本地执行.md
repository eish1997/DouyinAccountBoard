# 本地合成测试

仅使用 `python -B run_isolated_tests.py --root .synthetic-tests/<新的唯一名称> test_release_isolation test_release_shared test_release_package`。
目录必须不存在，启动器创建标识后先安装保护，再加载白名单测试；报告在该根的 test-report.json。
不执行 unittest discover；历史测试依赖客户派生种子，必须逐个改成独立合成 fixture 后才能加入白名单。
不运行历史 import_*、reimport_cleaned、reset_owner、Worker或部署脚本，不读取任何实际配置。

应用缺省数据目录和网站缺省配置已移除；直接 `python app.py` 会拒绝。
有授权的既有服务需要显式 DOUYIN_BOARD_DATA_DIR 与已有初始化库，但本开发任务不执行该流程。
网站启动必须显式 --config；现配置校验仍绑定历史正式目录，T05 改造前不能用它运行测试服务。
测试服务由已审查 fixture 在127.0.0.1随机端口启动，关闭在finally中执行。

包工具仅构建源码快照，不是可部署制品；不得把旧桌面包或整个项目目录交给员工。
后续需补齐目标数据库、迁移、Excel依赖、容器、安全入口与平台验收，再生成真正发布候选。
