# 隔离浏览器验收

仅用于新建合成环境，不读取现有浏览器profile、Cookie或业务库。

工具：项目`.local-tools/browser-tests/node_modules/playwright-core`固定1.64.1，package-lock归档于evidence/loop-0031。npm使用项目独立空user/global配置、项目cache、--ignore-scripts；未全局安装或升级。浏览器使用现有Chrome可执行文件，版本155.0.8059.80，但由Playwright创建全新临时profile及独立上下文。TEMP/TMP均在本轮新建合成根目录内。浏览器页面请求只允许该本机HTTP origin，后台网络/组件更新/同步关闭。

复现：项目venv运行`python -B probe_postgresql.py --root .synthetic-tests/<全新目录名> --browser-checks`。需要本项目免安装PG及上述Node依赖。测试启动新PG、web_server.py和无头Chrome，finally关闭浏览器及Web/PG。浏览器测试超时仅终止本轮拥有的Node进程树，不按浏览器名称搜索或终止用户进程。

loop-0031-b：人员办公室创建、范围保存回读、员工筛选、账号/卡/手机新增及无页面脚本异常共7项通过，PG基础8项通过。服务已关闭，源码哈希包含全部发布白名单静态资源。截图均为合成页面；人员弹窗及手机列表已目视核对。账号长表单可滚动，当前截图未覆盖底部全部字段，不声称完整视觉验收。

未覆盖：多浏览器/移动端、无障碍、完整权限矩阵、幂等/断网界面、Excel、恢复、目标负载、CloudBase与HTTPS平台验收。局部浏览器通过不等于第一版通过或上线。
