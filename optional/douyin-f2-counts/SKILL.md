# 抖音作品数量查询

使用配套 `scripts/douyin_counts.py`，从用户资料接口的 `user.aweme_count` 读取作品总数，无需逐页下载作品。先阅读 [使用说明](references/usage.md) 完成独立环境安装与首次登录。

## 输入与操作

- 支持直接接收抖音号：TXT 每行一个，或 JSON `["97350513058"]` / `[{"account":"97350513058"}]`。程序先在正常抖音用户搜索中按真实抖音号精确匹配内部标识，再读取数量，不要求使用者提供主页。仍兼容完整 `https://www.douyin.com/user/MS4w...` 主页和 `MS4w...` 标识。不能把数字号拼成主页；搜索无精确匹配、多个匹配或需要验证时记失败，不按昵称猜测。
- 用户没提供账号列表时，只有在其要求抽样时才找候选主页；公开索引可以发现主页，但索引里的旧数量不能当实时结果。随机抽样的候选范围应说明。
- 首次使用独立浏览器目录运行 `login`，由使用者正常登录；出现验证码由其手动完成。已有本 skill 的会话目录可直接复用。不要读取其他浏览器的密码库，不要求使用者发送 Cookie。
- 运行 `query` 顺序采集，默认每次间隔 3 秒；不要宣称这一间隔保证不触发风控。脚本只向抖音发送会话信息，不调用第三方数据接口。

## 判断结果

只有接口返回有效 `aweme_count`、账号标识和匹配的 sec_uid 时才记为成功，0 是合法数量。缺字段、空响应、私密账号或请求异常记为失败，数量保留为空。连续失败达到阈值后停止余下请求并标为跳过，避免盲目重试。

向用户交付昵称、抖音号、数量、北京时间和可点击的完整主页链接。HTML 报表可直接点击昵称；同时保存 JSON 与 CSV。说明成功数、失败数和跳过数；不能把历史结果或失败当成最新数据。

## 已验证与限制

2026-10-19，Windows / Python 3.14 / Playwright 1.61.0，F2 提交 `f6be8c0ffba9a127075bbeafe4838716650b6325`：已有独立登录会话下，先成功查询 6 个账号，再成功查询另外 20 个账号；游客请求曾返回 HTTP 200 空正文。首次登录仍需人工操作，长期每日无人值守的稳定性未验证。

本机2026-10-20已跑通纯抖音号输入的单账号真实链路：输入97350513058，自动搜索精确匹配“风笛道路救援”，F2返回1032个作品（北京时间02:26:54）。用户此前手动完成过搜索安全验证，最终一次query无需额外人工操作即成功；不代表长期无人值守或大批量稳定性已验证。9项本地测试通过，包括隐藏验证iframe、verify_check响应、验证后成功状态清除、身份冲突及0数量。

搜索响应HTTP200仍可能携带search_nil_info.search_nil_type=verify_check，需要人工处理；--interactive保留窗口等待本人完成。成功身份响应会清除旧验证标记，但真实可见挑战仍会暂停。人工验证后查询数量前重读同一独立会话状态，不读取其他浏览器凭据。

固定源码提交而非只安装 PyPI 同名版本：该开发分支源码内版本号仍为 0.0.1.7，但含较新的请求头处理。不要因此误认为任意 0.0.1.7 包都等价。

只有用户要求定时运行时才配置调度；本 skill 本身不会创建任务。每日采集应保存各次输出，失败时保留旧快照并标明旧时间，不能覆盖成 0。
